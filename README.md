# Customer Segmentation using RFM Analysis in PostgreSQL

## Source
Dataset from Kaggle showing transaction records 
from a UK online retail store between December 2009 and December 2011

## Reference date 
The newest invoice date from dataset (09.12.2011)

## Tech Stack
* PostgreSQL
* DBeaver
* Git/Github

## Methodology 
RFM Logic calculated on:
- Recency - Interval between newest invoice of each customer and reference date
- Frequency - Total number of unique invoices/orders per customer
- Monetary - Total revenue generated by the customer

Customers are segmented into 5 tiers based on each metric using the NTILE window function 
and using CONCAT to join all 3 of them to make rank: 
from 111 (lowest rank) to 555 (highest rank)

## Insights
The analysis reveals a highly polarized customer base, dominated by two extreme segments:
* The largest segment consists of high-value VIP clients (555) with 346 total
* Second largest group is churned customers (111) with 251 total

## Recommendation after analysis
* Early access to new products for loyal customers to keep them 
* Implement an automated win-back email campaign offering a one-time discount
to re-engage churned customers, while strictly monitoring ROI
